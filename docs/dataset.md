# قالب واژگان / قالب مجموعه داده

## `data/word-atlas.json`

آرایه ای که بر اساس مسیر یادگیری مرتب شده است (CEFR از آسان به دشوار، موضوعات را در همان سطح تقسیم می کند). هر ورودی:

| فیلد | نوع | توضیحات |
| --- | --- | --- |
| `id`| رشته | URL یک شناسه منحصر به فرد امن، که برای مثال نام فایل رسانه ای نیز می باشد`principle`、`day-off` |
| `w`| رشته | پیشوند |
| `uk` / `us`| رشته | IPA بریتانیا/آمریکایی با اسلش |
| `senses` | `{pos, zh, en}[]`| 1-3 معانی: بخشی از گفتار، تعریف چینی، تعریف مختصر انگلیسی |
| `ex` | `{en, zh}[]`| دو نمونه اصلی:`ex[0]`جملات کوتاه روزانه،`ex[1]`جملات طولانی متن آیلتس |
| `col`| رشته[] | ترکیب بندی های رایج، قالب ها`english｜فارسی` |
| `fam`| رشته[] | خانواده کلمه، قالب`word (pos)` |
| `syn` / `ant`| رشته[] | مترادف / متضاد |
| `tip`| رشته | نکته استفاده یا تحلیل چینی |
| `cefr` | `A1`…`C2`| سختی تخمینی |
| `topic`| رشته | یکی از 19 موضوع: آموزش، کار، فناوری، علم، محیط زیست، سلامت، جامعه، دولت، اقتصاد، رسانه، هنر، سفر، شهر، طبیعت، روزانه، احساس، تفکر، ورزش، تاریخ |
| `note`| رشته | اختیاری: یادآوری استفاده (توهین آمیز، استفاده منسوخ، دستورالعمل های املایی و غیره) |

## `data/word-atlas.csv`

نسخه جدول با همان محتوا، برای فیلدهای چند ارزشی` | `、` ; `یا`, `اتصال، رمزگذاری UTF-8.

## داده های صفحه وب`public/atlas/`

- `index.json`: شاخص فشرده،`words`هر عمل`[id, word, zh, ipa, cefrIndex, topicIndex, media]`。`media`علامت بیت است:`1`تصویرسازی،`2`تلفظ انگلیسی،`4`صدای آمریکایی،`8`جملات مثال با صدای بلند خوانده می شود.
- `entries/<n>.json`: ورودی های کامل، 100 ورودی در هر بلوک، شماره.`n`بلوک مربوط به شاخص در است`n*100`رسیدن`n*100+99`باشه
- `img/<id>.webp`（512px）、`thumb/<id>.webp`（256px）。
- `audio/uk/<id>.mp3`、`audio/us/<id>.mp3`、`audio/ex/<id>.mp3`（`ex[0]`خواندن با صدای بلند).

پوشش رسانه ای بر اساس`index.json`بیت‌مارک‌ها در معرض تغییر هستند، فرض نکنید که هر کلمه همه فایل‌ها را دارد.
